# Emergency RGB Light

A simple native Android screen-light app with Tihar Jhilmili, Emergency, Rainbow, Disco, and Running Light modes.

## Build
- Open this project in Android Studio (JDK 17, Android SDK 35), or push it to GitHub.
- GitHub Actions builds a debug APK on pushes to `main`/`master` and on manual workflow dispatch.
- Download the APK from the workflow run's **Artifacts** section.

## Compatibility
Minimum Android version: Android 7.0 (API 24). The light effects are drawn on the display; this does not change the color of the phone's rear LED flash.

## Note
This is a starter project. Test the APK on your device before distributing it.
